# React + Vite

This editor is based on the template provides through IntelliJ

I single-prompted Claude to produce an editor based on provided data, and this is what it came up with. It functions somewhat, has some visual quirks, and doesn't save any data yet.

Useful if you want to make something quick for the CPPTextAdventure repo, and don't want to manually edit everything. A more use friendly editor (with actually clickable action types, referencing, etc.) would be nice, but this is at least marginally better.
